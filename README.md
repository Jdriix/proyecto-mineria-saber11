# Proyecto Minería de Datos - Saber 11

## Descripción

Este proyecto tiene como objetivo realizar un proceso de minería de datos
sobre información relacionada con las pruebas Saber 11.

## Estructura del proyecto

- `data/raw/`: datos originales.
- `data/processed/`: datos procesados y limpiados.
- `notebooks/`: notebooks de análisis.
- `docs/`: documentación adicional.

## Notebooks

1. `01_adquisicion_cruce_diccionario` - Exploración inicial de los datos.
2. `01_adquisicion_cruce_diccionario` - Limpieza y preparación de los datos.

3. `04_checkpoint1_saber11` - Análisis de los datos.
4. `04_checkpoint1_saber11` - Visualización de resultados.
